# 흥미(T22) 문구 수정 — 2026-11-06

프로덕션 DB(`survey_questions.T2_2_interest`)의 분야명·설명을 고친 기록과 **되돌리기용 원본 백업**.
문구는 랜딩 `/survey`와 앱 자기이해 검사가 함께 쓴다. 고치면 두 화면에 바로 적용된다.

## 무엇을 바꿨나

- 분야명 5개(`field_name`): 경영과 행정, 교육과 훈련, 수학, 건축과 설계, 상품 제조와 공정
- 설명 24개(`field_definition`): 띄어쓰기 통일, '및' → '과/와', 끝맺음·표현 정리
- 항목 ID·개수(33)는 그대로 → 응답·추천 계산 영향 없음(추천은 ID → KN 코드로 연결)
- 분야명을 바꾼 것은 이번이 처음이다(10-19 는 설명만)

반영 후 `GET /api/survey/form` 대조: 33/33 일치.

## 진로백과와의 관계

진로백과는 고용24 기반 `reference_data.career_attributes`(KN)를 쓰고 이번 수정과 별개다. 코드로 연결돼 충돌은 없지만,
표기는 달라진다: 분야명 7개, 설명 30개가 검사와 진로백과에서 다르다. 진로백과 쪽은 고치지 않았다.
`reference_data.survey_elements` 의 T22 복사본에는 옛 문구가 남아 있다. API·앱·랜딩은 T22 에 이 복사본을 쓰지 않는다(어드민은 미확인).
