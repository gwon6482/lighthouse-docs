### 1. Section8 영상이 프레임 둥근 모서리 밖으로 삐져나오던 것 (`768c74a`)

영상은 사각형이라 **하단 좌우 모서리가 프레임의 둥근 모서리를 벗어났다.**
실측: 영상 사각형 `x 449~1687 / y 501~3001` 인데 `y=3001` 에서 폰 본체는 `543~1590` 뿐 →
좌우 각각 **97px**(CSS 약 20px) 튀어나와 노란 배경 위에 흰 사각이 보였다.

> 기존 주석의 **"넘치는 모서리는 불투명 베젤이 가린다" 는 틀렸다.**
> 베젤도 모서리에서는 둥글게 깎여 있어 못 가린다.

**영상에 `border-radius` 를 주는 방법은 해가 없다.** 프레임 모서리는 아이폰식 스퀘어클
(연속 곡률)이고 CSS 는 원호라, 구멍을 다 덮으려면 본체를 뚫고 본체 안에 넣으면 구멍이 드러난다.
반경 0~460px(5px 간격) × 영상 배율 1.00~1.06 을 전수 탐색했지만 두 조건을 동시에
만족하는 값이 **하나도 없었다.**

→ 영상 자체가 아니라 **폰 본체 모양의 마스크(`.section8_video_mask`, `overflow:hidden` +
`border-radius`)로 잘라낸다.** 마스크는 구멍이 아니라 본체 기준이라 여유가 크다.

| | 값 (frame.png 2139×3337 이미지 좌표) |
|---|---|
| 본체(측면 버튼 제외) | x 418~1717 / y 322~3016 — **버튼은 본체보다 9px 더 튀어나와 있다** |
| 마스크 | 본체에서 26px 안쪽, 반경 170px |
| 여유 | 본체 안쪽 19px / 구멍 덮는 19px (전 행 스캔) |

- 마스크 반경은 `13.633% / 6.435%` — **한 값짜리 %로 쓰면 가로세로가 달라 타원이 된다**
- 영상은 마스크 기준 %로 다시 계산해 넣는다. `transform` 으로 가운데 맞추지 않는다 —
  변형된 자식은 Safari 에서 부모의 `overflow` 클리핑을 빠져나가는 일이 있다
- 마스크 수치를 바꾸면 `.section8_video` 의 환산값도 같이 바꿔야 한다

검증: 렌더 스크린샷을 캔버스에 올려 **본체 바깥 5~45px 구간의 흰 픽셀**을 셌다.
390px 하단 모서리 기준 마스크 끔 **414건 → 켬 0건**. 구멍 안 노란 픽셀 0건. 390/430/768/1440 동일.

### 2. 부채꼴 목업 마우스 오버 시 맨 앞으로 (`5f993e4`)

태블릿 이상(부채꼴, ≥768)에서 마우스 올린 낱장이 맨 앞으로 온다.
`z-index` 는 전환되지 않으므로(정수 사이 보간은 의미가 없다) `translateY(-20px) scale(1.05)`
\+ CSS 그림자로 "떠오른다" 를 만들고(`$fan-lift-duration` 320ms), z 는 그 순간 바뀐다.

> ⚠️ **CSS `:hover` 로는 못 한다.** 낱장은 절반 가까이가 투명 드롭섀도라
> 오른쪽 장의 **이미지 상자**가 왼쪽 장의 **보이는 본체**를 덮어버린다
> (2번 상자가 1번 본체를 컨테이너 폭 19.7~48.3% 구간에서 가린다).
> → `MockupDeck.vue` 의 `hitTest()` 가 본체 사각형으로 직접 판정한다.
> 겹침은 항상 왼→오른이므로 **뒤에서부터** 훑어야 눈에 보이는 장이 잡힌다.

> ⚠️ **좌표는 `getBoundingClientRect` 가 아니라 `offset*`.**
> 떠오른 장에는 transform 이 걸려 있어 rect 가 그만큼 움직인 값을 준다 → 커서가 본체 경계
> 근처면 "떴다가 커서를 벗어나 내려가고 다시 뜨는" 진동이 생긴다.
> `offset*` 은 transform 이전의 레이아웃 좌표라 그 문제가 없다.

> ⚠️ **선택자에서 `img` 를 빼면 안 된다.** z-index 는 `mockup-fan-geometry` 가
> `img:nth-of-type(n)` 로 주고 있고 특이도가 **(0,2,1)** 이다. `.is-lifted` 만 쓰면
> (0,2,0) 이라 **져서 z 가 안 바뀐다** — transform 만 먹고 뒤에 깔린 채 커진다(실제로 당했다).

- 본체 비율 상수(`FAN_PAD_L 0.093` / `FAN_BODY_W 0.726` / `FAN_PAD_T 0.097` / `FAN_BODY_H 0.855`)는
  SCSS 의 `$fan-*` 과 **같은 값이어야 한다**. 부채꼴은 8/31 배포본 배치를 지키려고 옛 값을 쓴다
  (실측값 `$mock-*` 은 덱 전용 — 9/3 일지 참조)
- 덱 구간(≤767)·마우스 없는 기기(`(hover:hover)` 불만족)에서는 동작하지 않는다
- 폭이 좁아져 덱으로 넘어가면 떠 있던 장을 내린다
- `prefers-reduced-motion` 이면 전환 0s, `mousemove` 는 `requestAnimationFrame` 으로 프레임당 1회

검증: 5개 섹션 전부 오버한 장이 `z-index: 10` 최상단. 겹침 구간에서는 위 장이 잡히고,
투명 그림자 위에서는 아무것도 안 뜬다. 모바일 0건, 폭 축소 시 해제, 가로 오버플로 0.
