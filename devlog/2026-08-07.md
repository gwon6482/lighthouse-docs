## 잔재 페이지 `/main` 제거 → `v0.1.5` 릴리스

사용자 판단: "career-achievement가 사실상 설계 이후 `/main`인데 `/main`이 쓸모없이 존재하는 페이지로 보인다."

`/main`은 `"준비 중인 페이지입니다"` 플레이스홀더인데 진입가드·로그인 리다이렉트가 활성 plan 보유자를 전부 여기로 보내고 있었다.
(다만 하단 나브가 정상 렌더돼 홈 탭으로 즉시 빠져나갈 수 있었으므로 "깨진 경로"는 아니었고, 군더더기 한 단계 수준이었다.)

- `/main` → `redirect: '/career-achievement'` (라우트는 남김 — PWA start_url·북마크 대비)
- 진입가드(`app.ts`)·로그인 후 replace(`AuthPage.vue`) 목적지를 `/career-achievement`로
- `useHardwareBack.ts` `ROOT_PATHS`에서 `/main` 제거, 겸사 `/main/before` 추가(그간 빠져 있어 설계 전 메인이 루트 취급을 못 받았음)
- `MainPage.vue` / `MainPage.scss` 삭제, test 셸 dev 런처의 전/후 선택 모달 제거
- 배포: `a82c689` → main(스테이징 run 31157015624) → `v0.1.5`(프로덕션 run 31157118160, 40s). 번들 실측으로 3개 변경 전부 확인, precache 135→134
