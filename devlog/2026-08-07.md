### ⚠️ 실측 기록 — 관리자 기본 비밀번호
프로덕션 admin.lighthouse.career에서 `admin@lighthouse.com` / `changeme` 로그인이 **여전히 성공**함을 재확인.
lighthouse-admin에 `d36577f chore: redeploy to apply rotated ADMIN_PASSWORD` 커밋은 있으나,
Vercel production env의 `ADMIN_PASSWORD`가 실제로 교체되지 않은 상태.
사용자가 위험을 인지한 상태에서 현행 유지를 선택했으므로 조치하지 않음.

향후 조치 시: Vercel → lighthouse-admin → Settings → Environment Variables → Production에서 값 변경 후 재배포.
NextAuth JWT 세션은 서버 무효화가 불가하므로, 기존 발급 세션까지 끊으려면 `AUTH_SECRET`도 함께 로테이션 필요.
