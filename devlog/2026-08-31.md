### 부채꼴 배치 — 이미지 상자가 아니라 "보이는 본체" 기준

목업 낱장에는 드롭섀도용 투명 여백이 **폭의 27%** 있고 **좌우 비대칭**(왼 9.3% / 오른 18.1%)이다.
이미지 상자를 그대로 늘어놓으면 폰이 작아지고 무리가 왼쪽으로 치우친다.
구 합성 PNG는 폰 무리에 딱 맞게 잘려 있었으므로 그대로는 절대 안 맞는다.

→ 여백만큼 **음수 오프셋으로 당겨** 본체가 컨테이너를 채우게 했다.
그 대가로 낱장이 컨테이너 밖으로 삐져나오므로 `section-shell`에 `overflow-x: clip`
(`hidden`이 아닌 이유: 스크롤 컨테이너를 만들지 않기 위해).

**수치는 눈대중이 아니라 원본 배치 참조 실측에서 역산했다.**
처음엔 git에서 되살린 구 합성 PNG를 역산하려 했으나 폰들이 맞닿아 있고 크기도 제각각이라
경계 분리가 불가능했다. 기획자가 무리 기준으로 크롭한 참조 5장(`assets/images/samples/`)을
받아서야 확정됐다 — **처음부터 참조를 요청했어야 했다.**

### 세로 단 순서는 섹션마다 다르다

참조 4장은 계단 순서가 서로 달랐다(구 랜딩이 섹션마다 손으로 배치).
한 번 이걸 하나로 통일했다가 "단조롭다"는 지적을 받고 되돌렸다.
**"기존과 통일"은 기하를 맞추라는 뜻이지 다양성을 없애라는 뜻이 아니었다.**

| 섹션 | 높이 순서 | 출처 |
|---|---|---|
| 3 자기이해 검사 | 1-2-3 | sample01 |
| 4 자기이해 결과 | 3-2-1 | 원본 없음 — 대비용 |
| 5 진로백과 | 2-1-3 | sample05 |
| 6 진로설계 | 2-3-1 | sample04 |
| 7 진로달성 | 2-1-3 | sample03 |

겹침(z-order)은 항상 왼→오른이고 **높이만** 바뀐다. 무리의 위·아래 끝은 순서와 무관하게
같으므로 `aspect-ratio`는 그대로다.

### 반응형

`section-shell` / `section-text` / `mockup-fan` 믹스인으로 Section3~7을 조립한다.
`height: 1080px` 고정 → `min-height`. Section1·2도 함께 처리했다.

**실측으로 잡은 함정 2건**

1. **1단 전환 브레이크포인트** — `$bp-tablet`(768)에 걸었더니 **768~1430px 구간에서
   텍스트(565)+목업(720)+gap이 뷰포트를 넘었다**(834px에서 555px 오버플로).
   → `$bp-section`(1024) 신설 + `flex: none` → `flex: 0 1`로 축소 허용

2. **CSS 소스 순서** — `section-shell`이 만든 `@media(max-width:1024){ .inner{column} }`
   **뒤에** `.inner{row-reverse}`를 그냥 선언하면 특이도 동률 + 소스 뒤라서 **이겨버린다.**
   834px에서 4·6번 섹션이 2단 그대로였다.
   → `@mixin section-two-col`(min-width: 1025)로 범위를 걸어야 한다

가로 오버플로 0 실측: 1920 / 1440 / 1280 / 1100 / 1024 / 834 / 768 / 600 / 480 / 390 / 360 / 320px

### Section8 영상 — 화면에 완전히 들어왔을 때만 재생

`autoplay` 제거 + IntersectionObserver. 화면 밖이면 멈추고 다시 들어오면 이어서 재생한다.

> ⚠️ **`threshold: 1`을 쓰면 안 된다.** 데스크탑 영상 영역이 약 854px인데 노트북 뷰포트는
> 그보다 짧은 경우가 많다. 요소가 뷰포트보다 크면 `intersectionRatio`의 **최대값이
> `뷰포트높이 ÷ 요소높이`**라 1에 영원히 도달하지 못한다 → 재생이 아예 안 된다.
> "지금 가능한 최대 노출"에 도달했는지로 판단해야 한다(1280×640에서 최대 75%, 정상 재생 확인).

영상이 앱 스플래시로 시작해 **0초 프레임이 거의 백지**다. autoplay 시절엔 안 보이던 문제라
5초 프레임을 뽑아 `poster`로 지정했다(18KB).

> 처음엔 JS로 `currentTime`을 옮기려 했으나 **헤드리스 Chrome에서 시크가 먹지 않는다**
> (CDP로 직접 넣어도 0 그대로). 검증 못 하는 코드를 남기는 대신 `poster` 속성으로 교체했다.

### 검증 방법 — Chrome CDP

`sips` 크롭 추정이 부정확해서 CDP 스크립트를 만들어 썼다:
섹션 좌표를 재고 섹션별로 촬영하고, 스크롤 위치를 바꿔가며 `video.paused`를 읽는다.
**스플래시가 4초간 화면을 덮으므로(AppSplash `HOLD_MS`) 5초 이상 기다린 뒤 찍어야 한다.**

라이브 검증(www.lighthouse.career): 목업 webp 15개 참조, 구 PNG 0, `autoplay` 0,
`poster` 존재, 가로 오버플로 0(1440/834/390), 영상 재생 동작 정상.
