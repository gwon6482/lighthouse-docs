### ⚠️ 구조 정정 — 준비과정·채용 탭은 API를 쓰지 않는다

기존 frontend/progress.md에 "`GET /api/job/:jobCode/preparation`·`/recruitment` 백엔드 미구현"으로
적혀 있었으나, 실제 화면은 **애초에 그 API를 호출하지 않는다**.

| 탭 | 실제 데이터 출처 |
|---|---|
| 후기 | **API/DB** — `ReviewTab.vue` → `fetchJobReviews()` → `job_data.job_reviews` |
| 준비과정 | **FE 하드코딩** — `PreparationTab.vue`의 `SAMPLE_JOURNEYS_BY_JOB` |
| 채용 | **FE 하드코딩** — `RecruitmentTab.vue`의 `SAMPLE_POSTINGS_BY_JOB` |

`encyclopedia.api.ts`에 preparation/recruitment 호출 함수는 존재하지만 **어떤 컴포넌트도 쓰지 않는
dead code**. 두 경로 모두 API 404이며 013601도 마찬가지인데 화면이 채워져 보였던 이유가 이것.
→ 두 탭의 DB 이관은 **미착수 상태의 별도 과제**로 남는다.
