## `/survey` 완료 화면 · 결과 내보내기 (랜딩 `dev`, API `567abd4`)

- 완료 화면: [결과 내보내기] [설문 공유하기] + 한 줄 안내 / [라이트하우스 둘러보기](노란·로고, 랜딩 `/`로)
- **이미지(PNG)**: 화면 결과지를 감싸는 상자를 통째로 캡처(html-to-image). 결과지 내부 구조에 의존하지 않는다
  (약속: ready 신호 · 같은 도메인 그림 · `data-export-skip`). 성격 그림 9장은 앱 도메인에 CORS 가 없어 랜딩 `public/survey/t1` 로 복사(9MB→108KB webp)
- **PDF**: TCI 결과지를 참고한 **전용 A4 양식** 4쪽(`components/survey/report/`). 화면을 찍어 자르는 방식은
  픽셀 쪽나눔을 여러 번 다듬었지만 늘 어색해서 폐기했다. 문구 `reportText.ts` / 색 `report.scss` / 쪽 `PAGES`
- 파일명 `라이트하우스_검사결과_{성격유형}_{YYYY-MM-DD}.{png|pdf}`
- API: 결과 응답에 `completed_at`(검사일). ⚠️ `submitted_at` 은 **첫 중간 저장** 시각이라 쓰면 안 된다
- ⚠️ iOS 는 수 초 뒤 `navigator.share` 를 거부 → 만들기/저장을 두 번 클릭으로 나눔
- 미검증: iPhone Safari · 카톡 인앱 실기기
